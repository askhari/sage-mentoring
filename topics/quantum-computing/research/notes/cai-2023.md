## Definition and QEM vs QEC
- The review defines QEM as algorithmic schemes that cut the noise-induced bias in an expectation value by post-processing outputs of an ensemble of circuit runs, using circuits at the same noise level as the original or higher (p. 2, Sec. I) → error-mitigation
- Per individual run the noise stays equal or grows; only the ensemble average is improved. QEC instead lowers noise's effect in every single run (p. 2, Sec. I; p. 25, Sec. IV.D) → error-mitigation
- QEM targets expectation values of observables (average of repeated shots), not single-shot outputs such as phase estimation or Shor-type repeat-until-success; extending it beyond expectation values is an open problem (p. 3, Sec. II.A; p. 30, Sec. VI.A.5) → error-mitigation
- Wanted properties of a method: modest qubit overhead, an accuracy guarantee (error bound), simplicity, few assumptions about the final state (p. 3, Sec. I) → error-mitigation
- Rough comparison table (Table I, p. 26): QEC has high qubit overhead, runtime growing with code distance, constant sampling overhead, a required error threshold, and essential mid-circuit measurement; QEM has low qubit overhead, runtime similar to the unmitigated circuit, sampling overhead exponential in circuit size, no threshold (lower error rate just means lower overhead), and little or no mid-circuit measurement → error-mitigation
- Bias-variance trade-off: MSE = bias² + variance. QEM lowers bias (the systematic error that more shots cannot remove) but usually raises variance; the cost is the sampling overhead C_em = Var[mitigated]/Var[noisy], i.e. the factor of extra circuit runs needed for the same shot-noise level (pp. 3-4, Sec. II.A-B) → error-mitigation
- Sampling overhead can also be estimated from the range of the estimator via Hoeffding's inequality: C_em ~ (range of mitigated estimator / range of noisy estimator)² (p. 4, Eqs. 4-5) → error-mitigation
- Methods are split into two stages, noise calibration and response measurement. Learning-based methods are a way to do the calibration step. Classes: gate error mitigation (ZNE, PEC, readout), state error mitigation (symmetry, purity), observable error mitigation (subspace expansion, N-representability) (p. 21-22, Sec. IV.A.1) → error-mitigation
- Software packages Qermit, Mitiq and Qiskit each implement ZNE, PEC and measurement error mitigation; Qermit and Mitiq also include Clifford-based learning (p. 27, Sec. V) → error-mitigation
- Measurement error mitigation is present in almost all near-term experiments, so Table II omits it (pp. 11, 28) → error-mitigation

## Exponential sampling cost and fundamental limits
- Noise is modelled as independent Pauli faults with probabilities p_f. Fault-free probability P0 = prod(1-p_f); circuit fault rate λ = sum p_f (mean number of faults per run); for many locations P0 ≈ e^(-λ) (p. 5, Sec. II.C, Eqs. 6-8) → error-mitigation
- Even "magic" post-selection on fault-free runs costs C = e^λ (about 150 at λ=5, about 10^4 at λ=9). So QEM is unlikely to be efficient once λ goes well beyond order 1; the authors say this is an intuition, not a rigorous bound (p. 5, Sec. II.D) → error-mitigation
- Expectation values of Pauli observables under Pauli gate noise decay exponentially with λ. Resolving them needs an exponential number of samples, O(e^(βλ)), also for any linear combination of noisy circuits (p. 5, Sec. II.D; App. A.1.a, pp. 32-33) → error-mitigation
- QEM has a practical maximum circuit size (depth x qubits) for given hardware, with no error threshold like QEC. Better hardware simply enlarges the usable circuits, with no big technological jump needed (pp. 2-3, Sec. I) → error-mitigation
- Rigorous limits: lower bounds on the necessary samples from state distinguishability (relative entropy/trace distance, Takagi et al.) show exponential growth with circuit depth under local depolarising noise. Quek et al. show worst-case exponential growth in circuit size; for geometrically local circuits it is set by the gates in the observable's light cone (pp. 22-23, Sec. IV.B.1) → error-mitigation
- Quantum Fisher information bounds (Tsubouchi et al.): sampling cost of any QEM grows exponentially with depth for layered circuits under Markovian noise, and with depth and qubits for random circuits. For global depolarising noise the optimum is simple rescaling by (1-p)^(-L) (p. 23, Sec. IV.B.2) → error-mitigation
- Extraction-rate view: for post-processing methods the sampling overhead is C ~ q^-2; with direct post-selection it is C ~ q^-1. Symmetry verification reaches the best extraction rate (pp. 24, Sec. IV.B.3) → error-mitigation

## Zero-noise extrapolation (Sec. III.A, pp. 6-7)
- Idea: treat the noisy expectation value as a function of the circuit fault rate λ, measure it at boosted noise levels, and extrapolate the fit to λ=0. Introduced by Li and Benjamin and by Temme et al. (2017) → error-mitigation
- Linear extrapolation is the simplest case. With M data points a polynomial fit gives Richardson extrapolation (a weighted sum of the measured values), with bias O(λ^M) and sampling overhead that blows up if probed rates are large or closely spaced (equal gap: (2M-1)²). Valid in theory only for small λ, though an experiment worked at large λ → error-mitigation
- Exponential (or multi-exponential) extrapolation fits large-λ behaviour better, since a noisy Pauli expectation decays towards zero. It gave smaller bias than polynomial fits in some simulations and cloud experiments, especially for Pauli noise. It generally has no closed-form bias/variance → error-mitigation
- Noise scaling by pulse stretching (needs time-invariant noise and recalibrated pulses; demonstrated on superconducting hardware, harder for two-qubit cross-resonance gates) → error-mitigation
- Noise scaling by inserting extra gate sequences equivalent to identity (gate folding); easier to calibrate, but well-defined scaling mainly for depolarising gate noise and it may change the error model. An M-fold noise increase may mean up to M-fold runtime → error-mitigation
- ZNE is among the most widely implemented methods. Kim et al. 2023 used it on 127 qubits and 60 layers of two-qubit gates, in agreement with classical simulation (p. 7) → error-mitigation, nisq-era

## Probabilistic error cancellation (Sec. III.B, pp. 7-9)
- PEC writes the ideal operation as a real linear combination of implementable noisy operations, with some negative coefficients (a quasi-probability decomposition). It is sampled by Monte Carlo: pick circuit n with probability |α_n|/Q and multiply the result by sign(α_n)·Q, where Q = sum|α_n| → error-mitigation
- PEC can remove the bias completely (zero bias), at sampling overhead C ~ Q² that grows exponentially with λ. For Pauli noise of rate p per gate, per-gate overhead is ((1+p)/(1-p))², and for the whole circuit C ≈ e^(4λ) (p. 9, Eq. 18) → error-mitigation
- PEC can be applied partially: cost e^(4(λ - λ_em)) for reducing the fault rate from λ to λ_em, which also gives data points for extrapolation (p. 9) → error-mitigation
- It needs a full characterisation of the noisy basis operations, e.g. by gate set tomography; this is efficient only for local noise. Correlated noise can be handled by a sparse Pauli-Lindblad model, cycle benchmarking or learning. The overhead depends strongly on the basis, and PEC performs well when noise is Pauli (obtainable via twirling) (pp. 8-9) → error-mitigation
- Demonstrated experimentally on superconducting and trapped-ion platforms (p. 9, Table II) → error-mitigation

## Measurement (readout) error mitigation (Sec. III.C, pp. 9-11)
- Measurement noise is modelled by an assignment matrix A (a stochastic matrix, with A_xy the probability of reading x when y was prepared); ideal distribution = A^-1 times noisy distribution, and the ideal expectation value is O-vector·A^-1·p_noise (Eqs. 19-22) → error-mitigation
- Inverting A is a quasi-probability method like PEC, so the overhead grows exponentially with the measurement fault rate. A full 2^N matrix does not scale (done in early few-qubit experiments), so scalable variants assume uncorrelated qubits (tensor product) or a learned model with few parameters (continuous-time Markov generators), or work only in the subspace of observed bitstrings → error-mitigation
- Pauli twirling the measurement channel (random bit-flips) makes it diagonal, so the noisy Z-string expectation is just the ideal one rescaled by a factor that is divided out (p. 10-11, Eq. 24) → error-mitigation, quantum-noise-channels
- Inversion can give negative "probabilities" but the expectation estimate stays unbiased; alternative is constrained least squares/maximum likelihood or iterative Bayesian unfolding (p. 11) → error-mitigation

## Symmetry verification (Sec. III.D, pp. 11-13)
- Measure symmetries of the ideal state (operators commuting with the Hamiltonian, e.g. parity, total spin Z, particle number) and discard or post-process away runs that violate them. The post-selected state never has less overlap with the ideal state than the noisy one if the symmetry measurement is perfect → error-mitigation
- Direct (in-circuit) verification has overhead 1/pass-rate; the post-processing version (measure Pauli pieces of the projected observable and the projector) avoids extra circuit components but costs about the inverse pass-rate squared. It is a special case of subspace expansion → error-mitigation
- Limitation: it cannot mitigate errors that commute with all symmetries. Encoding in QEC codes is a way to add artificial symmetries, and then direct verification is just quantum error detection → error-mitigation
- Symmetry verification is a simple method used in a wide range of experiments, especially VQE-type; first natural-symmetry demonstration in an algorithm was Sagastizabal et al. 2019 (p. 13) → error-mitigation, variational-algorithms

## Purity constraints: virtual distillation and echo verification (Sec. III.E, pp. 13-16)
- Virtual distillation (VD, also called error suppression by derangement) uses M copies of the noisy state to estimate expectation values of the purified state ρ^M/Tr ρ^M, which converges exponentially in M to the dominant eigenvector; the leftover bias is the "coherent mismatch" between that eigenvector and the target state. Two copies already suppress errors by orders of magnitude in studies → error-mitigation
- It is measured with a copy-swap (cyclic permutation) operator, decomposable into transversal operations between copies (Hadamard-test ancillas otherwise); no purified state is ever prepared (pp. 14-15) → error-mitigation
- Sampling overhead for two-copy VD ~ Tr[ρ²]^-2 (≲ e^(4λ)); it grows exponentially with M (pp. 15-16) → error-mitigation
- Echo verification does the same job with two copies separated in time, using the inverse circuit and post-selection; overhead ~ Tr[ρ²]^-1 with smaller qubit footprint, but it cannot be parallelised over observables (p. 15) → error-mitigation
- An experiment by O'Brien et al. 2023 used VD and EV in variational ground-state energy estimation up to 20 qubits, getting 1-2 orders of magnitude error reduction (p. 16) → error-mitigation, variational-algorithms

## Subspace expansion, N-representability (Secs. III.F-G, pp. 16-18)
- Quantum subspace expansion finds the best state in the span of easily prepared states by solving a generalised eigenvalue problem H W = S W E, with H and S matrix elements measured on the quantum computer; the improved state need not be prepared. Original use targets coherent errors; applied to noisy mixed states it also removes incoherent errors (pp. 16-17) → error-mitigation
- Choosing expansion operators from symmetries, excitations or Hamiltonian powers; symmetry verification is the special case with the symmetry projector as expansion operator (p. 17) → error-mitigation
- N-representability: project a measured (noisy) reduced density matrix back to the nearest one satisfying known constraints (Hermiticity, antisymmetry, trace, positivity) via semidefinite programming; McWeeny purification iterates an idempotency fix of the 1-RDM, giving 1-2 orders of magnitude on a Hartree-Fock state in Google's experiment (pp. 17-18) → error-mitigation

## Learning-based mitigation (Sec. III.H, pp. 18-21)
- Learn the mitigation function's parameters with training circuits that resemble the target circuit and are classically simulable, by minimising the squared difference between ideal and mitigated results (Eq. 47) → error-mitigation
- Clifford data regression (Czarnik et al.): fit a linear rescale-and-shift E_0 ≈ θ0 + θ1 E using Clifford variants of the circuit; effective in experiments (p. 19, Eq. 48) → error-mitigation
- The linear form arises naturally under global depolarising noise (state = P0 ρ0 + (1-P0) I/2^N); the scale factor 1/P0 can be estimated from λ or Tr[ρ²]. Evidence suggests this is a good effective model for many gates (p. 19) → error-mitigation, quantum-noise-channels
- Clifford training can also train PEC coefficients (Strikis et al.); since Clifford gates form a 2-design, training on Clifford circuits minimises the loss for general circuits. Training cost is problem-specific and is an open question (pp. 19-21, 30) → error-mitigation

## Pauli twirling and noise tailoring (Sec. V.A, p. 27; App. A.2, pp. 32-33)
- Pauli twirling inserts random Pauli gates (conjugation) during compilation; it removes off-diagonal Pauli-basis terms and turns any channel into a Pauli channel; often most inserted Paulis can be absorbed into existing Paulis, at small gate cost → quantum-noise-channels
- Twirling over the Clifford group instead gives a depolarising channel, but Clifford gates (especially multi-qubit) are harder than Paulis → quantum-noise-channels
- Coherent errors accumulate faster than Pauli errors; the authors name converting them to Pauli noise as one of the most effective ways to handle them in QEM. Pauli noise helps each method (multi-exponential ZNE curves, cheaper PEC characterisation, easier analysis for symmetry/learning) (p. 27) → error-mitigation, quantum-noise-channels
- Coherent-vs-incoherent: coherence measured by how well a channel preserves purity; the most coherent are unitary errors, incoherent ones are stochastic Pauli channels; purity-based methods do not help with coherent errors (p. 27) → quantum-noise-channels

## Combinations and algorithmic errors
- Methods combine in parallel (e.g. ZNE/PEC for gates plus readout mitigation) or are concatenated, with overheads multiplying. ZNE on top of another method is awkward because the noise scaling may be ill-defined; PEC applied partially avoids that. Learning-based calibration replaces other methods' calibration (pp. 24-25, Sec. IV.C) → error-mitigation
- QEM can mitigate algorithmic/compilation errors, e.g. limited ansatz or Trotter error (ZNE over Trotter order, subspace expansion in VQE to overcome limited ansatz power), which QEC cannot (p. 29, Sec. V.C) → error-mitigation, variational-algorithms

## NISQ positioning
- In the NISQ era with limited coherence times, shallow circuits are used: variational circuits for simulation (VQE), QAOA and heuristic QML; each typically runs a short circuit and estimates an expectation value, which is where QEM fits (p. 2, Sec. I) → nisq-era, variational-algorithms
- Fault-tolerant devices are daunting in qubit counts (hundreds of thousands for classically intractable science problems, millions for industrial ones, citing Kivlichan 2020, Lee 2021), motivating mitigation before full fault tolerance (p. 2) → nisq-era
- QEM cannot alone handle large λ because of exponential overhead, but with its low cost it stretches the potential of near-term noisy devices (p. 5) → nisq-era
- Estimated VQE for a classically intractable Fermi-Hubbard ground state with symmetry verification plus extrapolation needs more than 100 parallel processors of 50 qubits and 10^-4 gate error, giving gate fidelity and qubit totals comparable to a fault-tolerant approach (p. 26, Sec. IV.D, citing Cai 2020) → nisq-era, resource-estimation
- Conclusion: QEM already part of many hardware demonstrations; useful sweet spot between noise removed and resources; expected to remain useful in the fault-tolerant era (pp. 30-31) → nisq-era
- Table II lists experiments: VQE with ZNE, symmetry, purity, subspace, learning on superconducting hardware, dynamics simulation with ZNE/PEC up to 127 qubits (p. 28) → nisq-era, variational-algorithms

## Combining QEM with QEC and early fault tolerance
- QEC and QEM are described as complementary: QEM can be applied on top of QEC (p. 26, Sec. IV.D) → error-mitigation
- In an "early fault-tolerant" era with residual logical error rates, all QEM methods can mitigate logical errors by replacing physical with logical qubits, gates and channels, as long as results come from expectation values (p. 28, Sec. V.B) → error-mitigation, logical-qubit-experiments
- Logical Clifford noise can be twirled into logical Pauli channels; extra Pauli corrections for PEC are applied virtually via Pauli-frame updates (p. 28) → quantum-noise-channels, logical-qubit-experiments
- Resource claims cited from other works: PEC at logical fault rate 10^-3 with sampling overhead 100 can cut physical-qubit overhead by 80% for some classically intractable problems (over 45% in many practical applications) (Suzuki et al., pp. 28-29); a circuit with 2000 T gates at physical error 10^-3 can be mitigated at overhead 1000 (Piveteau et al., p. 29) → resource-estimation
- Trade-off: more T gates reduces compilation error exponentially but raises the cost of QEM (p. 29) → resource-estimation
- Authors expect QEM to remain valuable in the fault-tolerant era because QEM alongside QEC can lower hardware requirements (p. 31) → error-mitigation
