- The Colour Index describes a dye's or pigment's essential colorant by application class and chemical class (home page) → colour-index-names
- Assigning a CI Generic Name (CIGN) and CI Constitution Number (CICN) identifies a colorant through a world-recognised system (home page) → colour-index-names
- It is run by two technical boards of industry professionals (dyes; pigments and solvent dyes); SDC Enterprises now controls it, working with SDC, AATCC, ETAD and CDIA; registered manufacturers may use CI names and numbers in marketing (home page) → colour-index-names
- A Generic Name combines a usage class, a hue and a serial number; the serial number follows the chronological order of registration. E.g. PB29 = C.I. Pigment Blue 29 = ultramarine, regardless of brand name (search summary of ci-explained / generic-name pages) → colour-index-names
- A colon in the serial (e.g. Pigment Red 48:1) marks a variant, usually chemically different, sometimes a different crystal modification (search summary) → colour-index-names
- Constitution Numbers relate to chemical structure; originally five digits, six digits for disclosures since 1997 (search summary of cicn-explained) → colour-index-names
- Natural colorants use N instead of P, e.g. NY6 = Natural Yellow 6, saffron (search summary) → colour-index-names
- The Generic Name defines only the essential colorant: commercial products under one name may differ in application, fastness or ecological properties, so check with the supplier (search summary) → colour-index-names, lightfastness
- Copyright of the nomenclature belongs to the Textile Chemists and Colorists side (search summary) → colour-index-names
